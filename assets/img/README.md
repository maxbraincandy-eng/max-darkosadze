# Photos / ფოტოები

Every image on the site points at a **fixed file name**. Copy your own photograph
into this folder using the exact name below and it appears everywhere it is used —
no HTML editing, no rebuild required.

საიტზე ყველა სურათს **ფიქსირებული სახელი** აქვს. ჩააგდეთ თქვენი ფოტო ამ საქაღალდეში
ქვემოთ მითითებული ზუსტი სახელით და ის ავტომატურად გამოჩნდება ყველგან, სადაც გამოიყენება —
HTML-ის შეცვლა ან თავიდან აგება საჭირო არ არის.

**In place already / უკვე განთავსებულია:** `hero.jpg`, `portrait.jpg`, `og.jpg`, `surgery.jpg`,
`aviation.jpg`, `writing.jpg`, `philosophy.jpg`, `film.jpg`, `public.jpg`, `honours.jpg`,

**Still empty / ჯერ ცარიელია:** `lecture.jpg` and `foundation.jpg` — these show a monogram block

Tall (portrait) photographs are fitted inside the wide article frame over a blurred copy of
themselves, so nothing is cropped away. `build.py` does not do this — the files in this folder are
already prepared.

Tips / რჩევები:
- JPEG at ~80% quality, under 500 KB per photo, keeps the site fast.
- Photographs are cropped to fill their frame; keep the subject near the centre.
- Captions are edited in `content/en.json` and `content/ka.json`, not here.
